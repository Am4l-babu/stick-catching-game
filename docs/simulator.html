This page is a browser model of the firmware in stick_catching_game.ino: the same state machine, game modes, 1 to 32 sticks, per-hook trim, Fisher-Yates shuffle, random gaps, servo timing and log messages. Falling physics and servo speed are approximations. Address options: ?sticks=10 (1 to 32), ?mode=marathon (classic, speedup, double, marathon), ?demo=1 (the bot plays).
